# propsens: Propensity Model Sensitivity Diagnostics for Matched Studies

Outcome-free diagnostics that measure how much a matched study depends
on the choice of propensity model. The definitions are given in the help
pages and in
[`vignette("definitions", package = "propsens")`](https://mostafa-abbas.github.io/propsens/articles/definitions.md).

## Details

The `importFrom` lines below declare the packages the diagnostics will
use, so that `R CMD check` sees every entry of `Imports` used.
